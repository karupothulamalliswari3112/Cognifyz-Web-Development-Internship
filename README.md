## What I Learned

- Structuring pages with semantic HTML and styling them with CSS
- Handling events and changing the page with JavaScript (colour changer, greeting by time, calculator)
- Building responsive layouts with the Bootstrap 5 grid and cards
- Using Flexbox and media queries to make a navigation bar work on desktop and mobile
- Creating a CSS-only hamburger menu with a checkbox
- Publishing static websites with GitHub Pages

## Run Locally

1. Clone or download this repository.
2. Open the root `index.html` in a browser, then choose a task. You can also open any task's `index.html` directly.

Level 2 Task 1 loads Bootstrap from a CDN, and the images load from Unsplash, so an internet connection is needed.
